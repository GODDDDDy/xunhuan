# 第30项结果：固定H，比较第二轮如何使用C

**检查日期：2026-10-16。状态：三组训练、完整验证和测试、服务器归档及CPU结果复核均已完成。本实例结束，不自动续训。**

本次回答的问题是：固定第一轮和原H，解除反馈状态上的强制C乘法，能否改善第二轮偏振修正；真实局部C是否比每图平均C提供额外收益。**结果没有达到事先规定的继续投入门槛。验证有微小正值，测试没有第二轮净PSNR收益，局部C也没有方向一致的增量。**

## 1．实验做了什么

|对象|唯一差异或作用|
|---|---|
|T1|共同的固定第一轮输出，不单独训练|
|A|旧使用规则：反馈状态先乘真实C，再与C一起进入融合|
|B|不再强制预乘；保留反馈状态和真实C，由同一类融合网络学习使用|
|D|使用B的规则，但将C替换成该样本C的空间均值图|

三组共用固定E1、原H和PolarFree，第二轮只通过偏振修正产生T2：`P2=clamp(P1+0.02*tanh(Rθ),0,1)`。每组独立训练两层适配器和零初始化偏振输出头，共292,896参数；没有直接RGB修正头、Q/M或任务解码器注入。

各组实际完成6000步，同一12000次训练裁剪呈现、覆盖5440张训练图，约2.21遍；seed2026。仅评价固定6000步终点，没有按验证或测试选择中间权重。完整设计、损失、来源及文献依据见[集中方案](../next_experiment_review_20261015/实验设计_审阅稿.md)。

预设主要继续判据是：B−A、B−T1均满足场景等权ΔPSNR≥+0.05dB、ΔSSIM≥0、至少6/8场景PSNR改善。B−D按相同门槛单独判断局部C贡献。**两项主比较和局部C比较均未通过。** 0.05dB是本项目事先约定的投入门槛，不是统计显著性或通用有效性标准。

对应结论：

- **解除预乘没有形成值得继续投入的效果。** B相对A的平均PSNR略高，但只在验证4/8、测试3/8场景为正，测试SSIM略降，不能据此声称新规则稳定更好。
- **当前第二轮没有建立净恢复价值。** 验证B−T1微小为正，测试为负；A、D的测试平均PSNR也低于T1。
- **局部C的额外贡献没有建立。** B−D的主PSNR在验证为正、测试为负，且幅度很小。不能把这组结果写成置信度引导有效。
- **本次没有重新检验H本身的质量排序能力。** H固定，改变的是下游使用规则。结果既不能否定H的已有排序证据，也不能据此定位为“H没用”或“其他模块必然是唯一原因”。
