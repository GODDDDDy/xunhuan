# 新偏振增强器：纠偏预训练与置信反馈实验结果

本次只运行最新一组，seed=2026。训练、PIDSR测试、下游完整验证与测试、本机归档核验及科研记录均已完成。GPU在绝对截止时间前已释放；完成后停用持续跟进。本记录将“实现及实验完成”与“方法带来有效收益”分别判断。

## 1. 当前结论

1. **增强器具有本次退化条件下的基础偏振纠偏能力。** PIDSR的30个测试场景中，四角度平均PSNR由31.408527升至34.498360 dB，增益3.089833 dB，SSIM由0.885488升至0.941193。29个场景PSNR提高，1个场景未提高；不能将均值改善表述为所有场景改善。
2. **质量头学到了一定的误差排序信息，但不能据此证明反馈有效。** 置信分数与局部T1误差的逐图空间Spearman均值在验证/测试分别为−0.436536/−0.451248；高分区域通常误差较小。误差尺度仍有校准偏差，分数不是正确概率。
3. **两轮反馈在本次训练中没有形成有实用意义的平均增益。** 测试T2−T1平均PSNR仅+0.000067412 dB，SSIM略降。不能宣布循环机制或置信反馈有效，也不能将这一结果单独归因于置信度、增强器或对齐模块。

## 2. 实验与权重来源

增强器采用PIDSR衍生的同分辨率恢复分支与SGSC跳接，从随机初始化进行纠偏预训练；无干净RGB引导，不训练超分分支。使用官方108个训练场景的既定98训练/10验证划分，30个官方测试场景仅在按验证选择权重后评价。周期AoLP距离、暗区/弱偏振/饱和掩码及正交关系目标残差属于本课题适配，**本实验不是完整PIDSR双轮超分方法的严格复现**。

实际预训练更新19000步，在预先锁定的稳定性判据成立后停止；按10个验证场景平均PSNR选用18000步权重。最近四次验证为16000/17000/18000/19000步，PSNR极差0.126438 dB、趋势+0.016850 dB/1000步，恢复损失相对极差1.407235%，均满足≤0.15、≤0.025、≤3%的判据。**这只说明固定验证条件下趋于稳定，不证明全局收敛或跨退化泛化。**

下游直接严格加载PolarFree官方net_g及官方net_d/net_le_dm，未被历史联合模型覆盖。增强器加载本次选定预训练权重。三个学习率为：纠偏主干2e−5，适配器/对齐投影/质量头1e−4，PolarFree主网最终1e−6。主网前500步冻结，501至700步渐进解冻预热；既有先验持续冻结并保留输入梯度。唯一一组训练8000步，裁剪128、有效batch 2，实际日志确认5440张训练图全部被使用。

对下载后的实际检查点再次进行CPU核验：初始化及500步的全部436个net_g状态张量均与官方源文件严格相等；初始化增强器的396个状态张量与本次选定预训练严格相等。8000步日志连续、损失与梯度范数均有限，所有实际分组学习率符合锁定规则。核验不执行新的模型推理或GPU实验。

## 4. 置信度与迭代诊断

质量头监督为4×4池化局部RGB MAE，输出正误差尺度b；`C=exp(−b/τ)`，本次仅用256个固定训练裁剪确定τ=0.025007669420032796。传入任务分支的C停止梯度，质量头输入也与任务分支梯度隔离。实测梯度核验确认两次增强器、两次PolarFree执行。

测试的C位于[0.6,0.7)的区域，平均预测误差0.010926，而实际T1误差0.016420；[0,0.1)区域预测0.110203，实际0.088911。分区误差有排序信息，但误差尺度并非精确校准。完整10个置信区间的样本量、预测/实际误差及T2迭代变化均保留于指标JSON；空区间明确记为null。

两轮偏振输出的平均绝对差在验证/测试约为3.759761e−5/4.084541e−5（按4×4网格位置加权，范围[0,1]）。**观测结论：第二轮偏振更新很小，且T2收益接近零。** PolarFree输入路径仍包含8位OpenCV量化，单级间隔1/255≈0.003922，明显大于这些平均更新。**待验证推论：小更新与量化路径可能共同限制反馈效果。** 均值小不等于所有像素量化后都相同；本次没有统计实际量化变化率，不能据此断言原因，更不能依据测试结果更改本轮模型或追加训练。

## 5. 官方性能保留与限制

固定28张验证探针绕过增强器，使用原始偏振与RGB，只监测官方主网性能保留。500步时参数漂移及PSNR/SSIM变化均严格为零，符合冻结要求。8000步相对官方起点平均PSNR提高0.960234 dB，SSIM提高0.005381891，参数相对L2变化0.005326644。

但28张中14张改善、14张下降，最大下降0.889253 dB，最大提高5.931802 dB。**探针均值未恶化不能证明所有场景没有遗忘。** 探针不用于选权重、自动改学习率或读取测试，也不能替代同预算匹配对照。

本次单seed、无匹配对照，不能证明新增增强方案优于旧方案，不能单独归因于SGSC、对齐或置信度。历史测试集已有多轮探索背景，不能称为从未使用的独立确认集。当前测试只用于评价，不用于权重选择、调参或决定追加实验。
