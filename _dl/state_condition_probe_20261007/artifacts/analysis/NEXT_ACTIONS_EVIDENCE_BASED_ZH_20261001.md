# 循环与联合优化：依据已有证据的下一步

日期：2026-10-01。性质：研究建议，未启动GPU推理、训练或下载。优先级以本文为准；此前多尺度R2P建议保留为历史候选，不自动执行。

## 研究问题

继续探索导师提出的任务感知、循环与联合优化。首先验证：在固定已训练的单轮系统后，第二次偏振更新能否利用第一轮任务状态改善输出。这里的RGB是同源派生表示，不能宣称新增独立观测。

## 现有证据

- G6不接R2P，仅微调net_g，validation/test图像平均PSNR分别提高0.707946/0.683813 dB；validation场景宏均SSIM下降，不能称整体质量提高。
- G4相对G6的图像平均PSNR为-0.017503/+0.010756 dB，单seed且方向翻转，未证实上游联合更新的附加价值。
- K2 feedback/no-feedback在validation上T2-T1为-0.04497/-0.06125 dB。两组第一轮PSNR也低于独立K1，因此必须分开考虑训练改变第一轮与推理第二步的影响。
- 固定24图、固定随机流的alpha端点检查通过；仅排除所检范围的同输入重复前向差异，不证明全实现无bug。
- Level C历史来自用户提供的摘要；原始配置和指标未在本轮定位，不能将其视为已独立复核，也不安排重复结构先验实验。
- G5为跨平台历史参考。其普通投影余弦损失、任务特征stop-gradient及梯度比标定，不是PolarAPP完整双层元学习对齐。G5没有收益，不能直接否定原论文机制。

来源：本项目K1_ABLATION_REPORT_ZH_20261001_v2.md及K1_ABLATION_V2_REVIEW_ZH_20261001.md；本目录JOINT_RECURRENT_EXPERIMENT_SUMMARY_ZH_20260930.md及endpoint_check_report_20260930.md。解释采用复核记录收紧后的口径。

## 文献直接支持的内容

1. PIDSR将同尺度空间/物理关系修复和跨尺度分辨率增强分成f/g两个阶段，循环伴随尺度变化。可借鉴互补职责，不能把它理解成重复任意同尺度修正即可改善。[Zhou等，CVPR2025，arXiv:2504.07758](https://arxiv.org/html/2504.07758v1)
2. PolarAPP使用内层试探更新和外层重建/任务目标学习对齐度量，再联合优化；还有冻结前端的任务微调。它的优化迭代不等同于推理时任务特征反馈循环。[Luo等，2026，arXiv:2603.23071v2，§3](https://arxiv.org/html/2603.23071v2)
3. 循环偏振去反射已有直接先例：RP2PN让偏振反射和透射估计相互精炼。因此“有循环”本身不是新增贡献。[Bian等，ICASSP2024，arXiv:2402.18178](https://arxiv.org/abs/2402.18178)

以下方案是根据本项目证据提出的假设检验，不是文献已经证明有效的结构。

## 第一优先级：现有K2检查点的幅度与目标诊断

无需训练。

1. 先复用固定24图；如进入新抽样，预先锁定场景/难度覆盖的validation诊断子集，记录组成，不按结果选图。既有24图实际为21 easy+3 hard，不能称难度平衡。
2. 对feedback/no-feedback各自正常计算并固定P1、P2，保留原第二轮配置；用P(alpha)=P1+alpha*(P2-P1)，alpha预定0、0.25、0.5、0.75、1。插值直接送TaskNet，不再过R2P。P1/P2已clamp，凸组合处于原范围，记录有效更新与原始delta的区别。
3. 恢复同一CPU/全部CUDA随机状态，固定原始RGB及权重，分别报告各alpha相对本模型T1的PSNR/SSIM与任务损失分项。端点必须保持一致性。
4. 并列图像均值、场景宏均、逐场景与改善/退化比例。若任务损失下降而PSNR/SSIM下降，只能说明观测目标存在分歧，不能因此宣称训练未生效。
5. 若小alpha高于alpha1但仍低于alpha0，只能称减轻退化。只有高于T1才是现有更新方向下的迭代收益线索。
6. 若非零alpha有明确探索性收益，先按锁定的全局设置扩到完整validation；不按每张图GT选择alpha作为可部署结果。全validation仍属于探索，不能作为独立最终验证。
7. 若所有已查非零alpha均无收益，就没有证据支持“只缩短现有第二步即可解决”；不直接宣称所有步长/方向都无效。

可选、在上述结果不足以判断时：在少量预定训练批次不更新权重，分别计算L(T1)、L(T2)在共享R2P参数上的梯度范数与夹角，以及各损失分项。这只诊断局部训练信号；需保留完整第二轮路径，并声明当前量化预处理含STE。负夹角不是共享权重导致泛化退化的因果证明。

## 第二优先级：固定第一轮的最小纠错训练

仅在幅度诊断无法给出可用方案、且决定继续探索时执行。提出的是新协议，不与历史K2混作单变量对照。

使用同服务器G4 no-alignment seed2026 step3000作为固定K1前端：冻结原R2P、全部TaskNet/先验。第一轮P1、T1、F1固定；第二次TaskNet仍用同一权重，但保留对新偏振输入的梯度。选G4是为了避免G5跨平台与对齐混淆，不是宣称G4最优。G6作为同协议评估的普通微调参照。

第二轮独立小残差纠错器接收原始P0、当前P1及可选F1；固定原始混合RGB。输出P2=clamp(P1+delta2)。只将新输出投影初始化为零，使初始P2=P1、T2=T1；避免同时零初始化多个串联门而切断有效学习。检查真实梯度后再正式训练。

| 组 | 配置 | 新训练 |
|---|---|---|
| A | 固定G4，只输出第一轮 | 无 |
| B | A加独立第二轮纠错器，无TaskNet反馈 | 只训练纠错器 |
| C | A加同规模纠错器，有第一轮TaskNet特征反馈 | 只训练纠错器及反馈投影 |

B/C应控制总可训练规模、初始化、采样/裁剪顺序、预算、优化器、精度与输出限幅。反馈功能与容量须分开：例如B用同维偏振特征条件分支作为容量对照，C用任务特征条件分支；不能将C多出的投影参数直接算作纯反馈效应。零反馈推理消融可补充依赖分析，但不替代B训练。具体对照构造须在实现前记录。

仅用已有任务损失监督T2；T1固定，L(T1)不参与优化。暂不新加alignment、物理损失或单调惩罚，不改RGB主输入，不改变TaskNet权重。使用预定固定步数（可先沿用3000步）作探索，不证明该预算足够达到最优。第一轮GT只用于训练/评估目标，不能生成推理反馈。

- B-A：固定第一轮后的额外可训练修正是否有条件性价值。
- C-B：任务特征条件是否优于同规模偏振条件纠错。
- C-A：这一新两轮协议能否改善自身第一轮。
- C-G6：是否显示超出普通微调的总体价值；它是整体方案比较。

该实验同时改变权重共享、初始化与训练阶段，因此不能用新旧K2差值宣称已证明共享权重是原因。若有效，再安排控制其他因素的共享/不共享消融。

## 第三优先级：有方向后再做联合优化与重复

若新第二轮有收益：先同平台补关键B/C配对seed，明确仅少量seed不能保证效应可判定；再比较冻结TaskNet与解冻net_g、固定第一轮与全模型联合。解冻组必须带同起点、相同步数的数据匹配G6继续微调对照，以隔离普通追加训练。

若B有效而C无额外价值：不把收益归为任务反馈；先研究普通二阶段修正。如果B/C均无明确收益，暂停这个具体第二轮协议，转向新的误差分解或表示假设，不自动增加K3/训练时长。

是否借鉴PolarAPP双层对齐应另立实验，不将其与第二轮结构同时改变。只有任务损失时，不能称完整复现PolarAPP重建+任务外层目标。

所有后续报告同时保留PSNR/SSIM、两种聚合、逐场景与负面结果。探索仍用validation；test已反复查看，正式确认需另行定义独立留出/外部评估，不能重新命名旧test为未见数据。计算量与推理次数也应报告。

## 当前动作排序

先做幅度与损失诊断；再按结果决定是否训练独立第二轮纠错器；有可重复收益后才解冻联合优化、做关键对照和确认性评估。当前不安排全七组补seed、K3、多模块同时扩展或大规模超参搜索。
