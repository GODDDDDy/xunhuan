# 第23项3000步末期收敛检查

日期：2026-10-14。用户要求对“尚未确认收敛”作实际检查。本检查仅分析已归档训练记录，未训练、未推理、未改变最终权重或选权重规则，未使用测试曲线调参，未恢复监控。

**结论：对齐项有平台迹象，但整个图像恢复任务的稳定收敛仍不能确认。**现有记录也不能证明全局“不收敛”，不能推出继续训练一定有效。之前只有“固定步数结束，尚未检查”的描述，现在有具体日志证据及明确缺项。

## 检查对象和完整性

输入为已核验最终包内3000条连续joint CSV，以及0/500/1000/1500/2000/2500/3000步的固定训练探针。每份输入大小/SHA重新与最终archive_manifest核验一致。四个固定裁剪的sample_id、来源预测浮点哈希全程一致；各探针标记training_only、used_for_selection=false。没有重新读取原图。

3000有效步、每步2图裁剪，共6000次图像裁剪采样，覆盖5440训练图，平均每图约1.10次采样。这不是每张原尺寸图已充分学习的证明。300次meta记录只在真正更新步骤取值，日志其他步骤中的0没有被误算成梯度下降或元损失下降。

## 3. 梯度和参数证据

最后两个窗口的适配器梯度norm均值0.0017133→0.0016280，减少约4.98%，全程没有单调降至接近零的轨迹。meta原始超梯度norm均值4.2961e-9→4.7080e-9，增加约9.59%；固定×1000缩放后的对应值按同一比例变化。它们均非零且有限，不等于任务还必然需要训练，也不等于优化出了故障。

**梯度norm不是参数更新norm**：Adam有状态、学习率和epsilon，不能用日志梯度大小伪造实际参数变化历史。日志没有逐步相对参数更新norm；每500步的last.pt被覆盖，归档没有全部历史参数检查点。因而无法补做完整的参数轨迹检查，缺项明确保留。

## 4. 能判断和不能判断的范围

- 支持的事后描述：对齐项趋平；随机窗口的任务/外层目标未持续下降；固定四裁剪末期平均任务误差升高；优化梯度仍有限、非零。
- 不能确认：整体图像恢复任务充分收敛、参数已稳定到驻点、模型继续学习一定能提升泛化、存在已证实过拟合或某个模块是根因。
- 缺少有代表性的固定验证样本学习曲线：本组只有最终完整评价，不能从终点PSNR重建“何时改善/何时变差”的过程。四训练探针不能代替它。
- 本检查为事后诊断，没有设置一个事后阈值然后冒充预先收敛判据。来源PIDSR预训练的19000步验证稳定记录，不能套用到本次新的协作联合优化。

这是对已有记录所能完成的检查，未因检查结果重开旧预算、追加训练、改变FA系数或改选中间权重。

## 解释依据与出处

Goodfellow, Bengio, Courville, *Deep Learning*, MIT Press, 2016，[第8章§8.1.2—8.1.3](https://www.deeplearningbook.org/contents/optimization.html)区分训练优化目标、泛化评价及小批量估计，并指出机器学习的停止与纯优化的驻点收敛并非同一概念。该文献支持这里对“梯度/任务/泛化”分开判断的原则；本组窗口变化及结论均是我们的实测和受限推论，不是该书关于本模型的直接结论。
