# 第二轮只修需要修的区域：局部更新判断建议

2026-10-11。本文回应用户关于保护第一轮好区域的提问，是待验证方案；没有实现、训练或启动新实验。已完成实验与权重保持原样。

## 为什么需要这个机制

最新两轮残差纠错实验完整验证/测试显示：第二轮平均PSNR小幅提高，图像平均SSIM下降。测试置信0–0.2区间的局部MAE降低，但0.2–0.3和0.5–0.9区间反而升高。质量分数有误差排序信息，却不能保证每次修改都有益。这是提出保护机制的探索依据，不是新门控已经有效的证据。[完整结果](POLAR_RESIDUAL_FEEDBACK_RESULTS_ZH_20261010.md)

目前质量分数C控制上一轮特征的可信贡献，并作为纠错头输入；最终RGB输出仍是T1加预测增量。代码没有明确规定某些区域必须复制T1。以往诊断中的C=0也不是下面所说的输出更新权重M=0，不能混为一谈。

## 两个不同的判断

第一项是“这里是否仍然需要修”：复用质量头预测的局部误差尺度，结合原RGB、真实偏振及第一轮特征，形成需要修正的区域判断。先检查训练内留出数据上的校准；当前C不是正确概率，不能直接把1−C称为错误掩码，更不能把DoLP当成质量置信度。

第二项是“这次修正是否值得接受”：第二轮先提出候选修正，再由小型比较头读取停止梯度的T1、候选结果、原始观测和对应特征，判断该区域修改后更好、近似不变还是更差。局部误差很大不等于当前候选能够修好它，因此只靠第一项不够。

建议将最终输出写成：

`Tfinal(x) = T1(x) + M(x) * ΔTcandidate(x)`

其中M在0至1之间，广播至RGB通道。对于被判定应保护或应拒绝修改的区域，M取0，直接复制T1；明确需要修且候选被判断有益的区域允许较大更新；边界和不确定区域采用较小权重并检查接缝。M=0的输出像素可以严格保持不变，但模型仍可能错误划分区域。

门控放在最终RGB增量上，才能保护实际输出。只门控偏振或中间特征不能阻止其余通道改变RGB。第二轮仍可读取全图上下文；这是限制输出修改，不承诺减少第二轮计算，也不需要分块前向。

## 判断怎样学，怎样避免“全部不改”的捷径

训练时用训练集干净RGB比较T1与未门控候选的局部误差，构造“改善/近似不变/恶化”标签；标签和比较头输入停止梯度，不允许网络通过改变标签或质量头逃避监督。改善幅度很小时保留不确定区，不要求预测精确的微小PSNR增量。局部尺度、改善间隔及阈值需在未来正式训练前使用训练内留出数据和验证规则确定，不能从现有测试区间反推。

保留未门控候选的恢复监督和门控后结果的全图监督，使修正分支必须学会提出有效修改，而不只是让M全部归零。训练中对第一轮真实低误差区域的多余修改给予有限保护约束，同时检查边缘/梯度误差；这只是训练偏好，不是未知图像不退化的保证。

最初固定第一轮参考能力，让新增修正/判断分支先学会工作；若之后联合微调，保留T1监督、固定参考监测及既有分组学习率原则，防止通过把T1变差制造虚假的迭代收益。推理只使用观测、预测和网络特征，不输入GT，也不计算真实误差。

## 文献依据与本课题的新增假设

- Dong等，**Location-Aware Single Image Reflection Removal**，ICCV 2021，5017–5026：预测反射主导位置，用位置图控制特征流并循环细化。直接支持区域信息参与去反射；反射位置不是T1正确区域，也不是候选收益判断。[官方论文页](https://openaccess.thecvf.com/content/ICCV2021/html/Dong_Location-Aware_Single_Image_Reflection_Removal_ICCV_2021_paper.html)
- Mao等，**AdaRevD: Adaptive Patch Exiting Reversible Decoder Pushes the Limit of Image Deblurring**，CVPR 2024，25681–25690：依据局部退化程度决定图块在哪个解码阶段退出。作者亦报告直接预测收益的回归误差可能大于后续阶段的微小收益，提醒我们不能把比较头当作必然准确的裁判。该方法用于去模糊的图块退出，不等于本方案的逐区域输出门控。[原文§4.3.2](https://arxiv.org/html/2406.09135v1)
- Chen等，**Restore, Assess, Repeat: A Unified Framework for Iterative Image Restoration**，CVPR 2026，15506–15515：比较修改前后质量，若判断新结果没有改善，则停止并保留旧状态。支持“提出修改后再判断是否接受”；其潜空间整体比较没有验证本课题的局部门控。[原文§3.3](https://arxiv.org/html/2603.26385v1)

将现有偏振观测、两轮残差修正、局部需要判断和候选收益判断组合，是本课题待验证设计。文献没有证明这套组合能在当前数据上提高PSNR和SSIM。

## 未来如何判定有用

除完整872验证/188测试的T1、最终输出及场景PSNR/SSIM外，需报告：原本低误差区域被改坏的比例、原本高误差区域被修好的比例、接受错误更新和拒绝有效更新的比例、门控覆盖率以及边缘变化。训练/验证中可用GT定义这些核查指标；评价用GT不等于推理用GT。

继续监测第一轮的绝对能力；不能只证明最终输出接近T1，也不能靠全拒绝获得“不变”的漂亮结果。局部误差改善不自动意味着SSIM提高。保留单seed、组合结构变化及现有测试集历史探索限制；本提问不计作新的正式实验，也不重新启用已结束的GPU预算。
