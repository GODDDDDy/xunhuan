# 第23项结果：单轮PolarAPP核心协作迁移

整理日期：2026-10-14。**协作训练3000步和完整872验证、188测试已完成，GPU评价于10月13日22:31:58结束。结果为小幅平均改善，跨场景稳定收益尚未确认；没有完成的普通续训对照，不能识别协作机制的独立贡献。**

## 1. 实际研究范围

遵照用户“先不管循环和置信”及最新“只跑协作训练”，本次推理只执行偏振增强器E → 浮点灰度桥/Stokes → PolarFree → RGB。H、Q、跨轮纠错状态、RGB纠错头、区域接受和动作成本判断均不构造。FANet仅参与训练，评价与部署不运行它。

实际起点是第22项最终联合模型中抽取的增强器396个状态张量及PolarFree主网436个状态张量，不是本组从官方主网重新开始，不是重新PIDSR预训练。对齐部分单独严格加载官方FANet；它通过同尺度接口接入，不能称完整照搬原版PolarAPP或真实EIT成像约束。

既有增强器、主网及先验冻结并eval，保留输入梯度。上下游共23856个新增残差适配参数，lr1e-4；FANet部分2001408参数，lr1e-5，其余冻结。保持参照是冻结来源偏振输出，**不是干净偏振GT或物理正确性的证明**。

普通微调原计划已被用户取消：2055步安全中止，原检查点、日志和父协议保留；不继续、不评价、不用于协作初始化。因此本报告只比较训练前来源单轮source和协作后meta，没有meta-control结果。

## 2. 训练与执行核验

固定seed2026、crop64、有效batch2微批1，完成3000联合更新、每10联合更新一次真实二阶元学习共300次，5440联合训练图全覆盖。内/外层固定训练31/12场景角色，各实际两样本均值；这些场景已被继承模型见过，不能称独立未见外层集。

FP32真实create_graph二阶，禁TF32；临时SGD1e-4不写回。外层RGBMSE固定×1000处理小超梯度数值量级，raw/scaled同时记录；Adam epsilon1e-8。任务RGBMSE+.02边缘MAE+.1来源偏振MSE保持；FA系数0.0013960204416974562仅在8个训练裁剪校准。每500步训练探针不挑权重或调参。

CSV独立核查3000个连续步号及300次非零超梯度记录；训练结束冻结审计通过，固定来源训练探针输出哈希不变。训练成功阶段约5431秒（1.51小时）；成功评价阶段约7372秒（2.05小时）。这些是实际阶段时间，先前1.72/4.63小时为最大训练图预估，不应覆盖真实收据。

权重核验、固定终点和一次/两次任务执行等接线检查只能证明执行条件，不能代替效果结论。没有收敛证明，也没有多seed稳健性验证。

1. crop128二阶预检显存不足；正式训练前两组共同改crop64，原代码、日志、状态和失败包保留。更小上下文是限制，评价仍原尺寸。

3. 用户“只跑协作训练”后control在2055步安全中止，meta为0步时重锁范围。原父协议和中止权重保留，meta仍原来源，未读正式验证/测试作此决定。
4. 协作训练完成后，评价因不存在55/hard的示例假设中断，尚未产生正式context/指标；归档又因活动watchdog文件更新而核验失败。原记录与未通过核验的临时tar保留，临时tar不能当作有效归档。
5. 独立恢复脚本仅修复固定示例规则/唯一目录与活动文件字节快照打包；冻结原代码、协议、网络、指标、最终权重不改。原CPU协调/独立watchdog重新登记，原预算不变，只恢复评价与归档，训练没有重跑。context与恢复收据记录原脚本/包装器SHA。

主包排除嵌套tar；两次预检失败包80/92文件、中止control包118文件、评价恢复有效失败包177文件已分别下载并逐文件核验。它们均是过程档案，不是正式结果。原未验证临时tar明确标记失败，不伪称验证成功。
