# K2傅里叶相位损失权重匹配实验：完整执行结果

日期：2026-10-02。两组均训练至3000步，并各完成872张validation评估。seed2026，单seed探索性结果；原历史文件保留。本报告的数值来自本次检查点、逐图指标和损失分项，不是推测。

## 结论

**当前训练目标确有值得修正的地方，但循环第二轮的独立价值仍未建立。** 在同起点、同结构、同数据和预算下，将每轮傅里叶相位损失系数从1改为0.1，最终T2的图像平均PSNR提高0.394838 dB，SSIM提高0.007246；场景宏均PSNR提高0.248262 dB，SSIM提高0.004589。

第一轮T1也提高了0.332597 dB。新组T2−T1只有图像均值+0.000995 dB、场景宏均+0.015114 dB，SSIM两口径仍为负；543/872张图的第二轮PSNR下降。因此不能把上述最终T2改善全部归于“多循环一次”。这些是本次条件下的观测差值，未证明统计显著、等价、跨seed可重复或独立泛化收益。

## 1. 实际执行与单变量

先修复旧梯度诊断绕过feedback的路径，再复查两组原5个schedule批次；之后开展本次**no-feedback共享权重K2**两臂训练。没有改变模型结构、反馈开关或轮数。

每轮任务损失为：`L1 + (1−SSIM) + c×FFT相位损失 + 0.1×VGG感知L1`。训练目标为：`0.5×L_task(T1;c) + L_task(T2;c) + λ×Align1`。

唯一主动改变的训练因素是c=1或0.1。这里c是训练损失系数，与前次推理插值alpha扫描不同，也不是偏振角损失。固定λ=0.030651881051471687，不重新标定。两组从PIDSR e42 R2P与官方net_g重新初始化Adam；seed2026、数据与crop schedule、batch2/crop128、R2P学习率1e-4、net_g学习率1e-5、裁剪集合与原TF32设置一致。先200步检查，再携带完整优化器状态恢复至3000步。

初始全模型与net_g状态SHA256相同；28张step0代理验证逐图两轮PSNR/SSIM差为0。评估固定step3000，使用完整872张validation，不使用proxy-best替代。额外损失记录复用同一正式前向输出，没有新增TaskNet前向；全部图像的损失算术均未改变CPU及CUDA随机流。

执行协议：[PHASE_OBJECTIVE_PROTOCOL_ZH_20261002.md](../../../../analysis/PHASE_OBJECTIVE_PROTOCOL_ZH_20261002.md)。0.1是预先固定的参照，不是通过本次数据搜索出的最优值，也不是完整PolarFree复现。

## 6. 可下与不可下的结论

本次固定条件的配对实验支持：**更换phase系数能改善这个K2训练配置的平均最终表现，原目标配置存在可改进空间。** 它不能证明phase是唯一根因，也不能证明0.1最优、物理偏振增强有效、feedback有效或循环普遍有效。

两组同时训练net_g和R2P；第一轮也明显改善。对历史G6的比较还混入目标变化。第二轮在新组仍有多数图像与多数场景的PSNR下降，SSIM两个均值为负。因此当前更准确的判断是“训练目标调整有效的线索增强，但第二轮纠错能力仍待解决”。

单seed、单预算；未估计跨seed变异、等价界限或总体效应置信区间。872张validation已参与探索，旧test已反复查看；本次不构成独立确认。两种聚合均合法，保留所有负面结果，不通过删场景或改聚合选择结论。
