# 固定H之后，第二轮怎样使用质量信息

2026-10-15。性质：文献、现有源码与历史实验分析；没有实现新机制、训练、GPU推理或下载。当前研究问题是使用已有反馈与质量估计，而不是默认更换反馈来源。

## 1. 对用户观点的评价

“H已具有可用质量信息，下一步应固定H、研究下游使用”是有证据支持的阶段安排。完整历史测试的184/188图具有正确方向的C误差排序，最新64验证图原H在20%面积中覆盖约37.66%的最差区域，高于随机同面积的20%期望。H不必先达到完美定位或校准才允许开展下游研究。

但该安排不等于已经证明H在所有条件下合格、或恢复失败只来自下游。更准确的研究命题是“在现有H能力给定时，是否存在更有效的使用方式”。固定第一轮和H既节约预算，也让使用方式成为可区分变量。若以后换第一轮或特征，旧H统计仍不能直接外推。

## 3. 当前代码实际上已经做过什么

核对第27项已归档源码与全路径条件入口：

- `feedback.make_context`已拼接C、1−C，并包含未乘C的任务参考特征和原始观测。
- 第二轮偏振增强器`TaskAdapter`将预测图/差图的投影与任务特征投影相加，再强制乘C；同时也把C作为输入通道。
- `feedback.fuse`用C乘上一轮任务参考特征，进入第二轮任务解码器融合。
- `feedback.correct`也含C乘参考特征，但保留其他未加权输入；输出是相对T1的有界残差。
- 这些融合/纠错部分已有任务恢复损失训练，不是只有质量代理监督。Q预测器单独存在stop-gradient边界，但不能因此声称全部C使用模块没有任务梯度。

因此，“加C通道”“软条件”“任务驱动训练”“保留观测”“残差修正”都不能再直接包装成尚未尝试的新方案。26条路径是核验覆盖计数，不等于26种独立机制。

可核查实现：`_dl/polar_quality_matched_candidate_20261015/artifacts/scripts/enhancer.py`的TaskAdapter（约第47行）、`feedback.py`的make_context/fuse/correct（约第56/72/80行），以及`server_scripts/polar_quality_matched_candidate_20261015/quality_forward.py`。

## 4. 值得优先检验的局部使用假设

**假设：把T1图像质量C直接作为第二轮偏振反馈特征的强制衰减系数，可能不适合其实际职责。**

当前偏振TaskAdapter的简化形式是：

`state = C * (prediction_projection(T1, I−T1) + task_projection(F1))`

H估计T1局部RGB误差，并未监督“F1各通道是否有用”或“偏振更新应当多大”。低C意味着结果差，不推出该位置的反馈特征无用或应少处理。反射强、纹理丢失等区域也许需要这些特征来产生修正。这是基于语义和文献的推论，不是已验证的失败原因。

应保留反面可能：低C位置确实也可能含不可靠特征，衰减可能有保护作用；现有上下文还提供未乘C的旁路，不能说差区域的全部信息都被切断。第18项C=1略好及第27项真实/常数条件不一致只是动机，没有定位此处因果关系。

优先候选是只在第二轮偏振TaskAdapter的两个既有尺度解除上述强制C乘法，保留同样的T1/F1/观测、同样的C通道、相同的可学习融合结构，令恢复目标学习是否及怎样利用C。原方案作为主动对照。不要同时改解码器/输出头的C乘法、换特征来源、另加1−C门控、改损失加权或新增Q/M。

这一候选的独特变化是“是否预先强制衰减偏振反馈状态”，不是首次提供软C。它也不是重做第14/27的真实C对无C/常数实验：两组保留完全相同的实际C，区别只在一类使用规则。

实施前必须处理共享参数边界：原r2p.adapters可能参与第一轮，不能直接把共享适配器解冻就声称第一轮固定。必须核对或隔离第二轮可训练部分，使第一轮逐张量/逐输出保持一致；具体训练边界、来源、初始化和预算尚未锁定。当前不为提出假设而启动新训练。

## 5. 什么结果才支持什么结论

- 新用法同时优于同预算原用法和T1，且结构指标与场景表现符合预设门槛：支持该处使用方式有改进价值，不能外推所有融合路径或所有H。
- 只优于原用法但不优于T1：只是减轻损害，未建立循环净价值。
- 优于T1但不优于原用法：循环可能有用，新使用规则的增量未成立。
- 没有明确改善：结束这一局部机制，不能改写成H无用，也不据此自动扩展其他门控。

即便成功，也不能据此独立认证C空间信息的价值，因为两组都接收实际C。研究顺序可先定位使用规则的问题，再根据最终方法主张决定必要确认，不能把未确认项自动全部列为待跑实验。

当前决定：支持将研究重心转向下游利用；提出上述单一局部候选作为下一步可讨论的具体机制。文献分析完成，执行协议尚未锁定，没有新增实现、训练、GPU评价或监控。
