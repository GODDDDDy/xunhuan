日期：2026-10-08。状态：置信机制仍为研究设计；不含置信度的直接T1两轮训练已完成追加10000步、872张validation及188张test。测试T2−T1图像平均PSNR为−0.01703706 dB，尚未显示稳定迭代收益，见[完整结果](DIRECT_T1_JOINT_RESULTS_ZH_20261008.md)。

当前执行范围已由用户更新：先运行不含置信度的直接T1两轮联合训练，完整继承现有带增强的K1权重，不重置增强头；见[当前执行协议](DIRECT_T1_JOINT_PROTOCOL_ZH_20261008.md)。下文仍是之后置信机制的设计记录，不能当作本次已加入的模块清单。

本记录承接导师提出的“固定完整大框架，再实现具体交互机制”。主线为偏振辅助去反射、上一轮任务结果反馈、两轮联合训练。早期设计曾提议用G6的net_g加上另行初始化的增强模块构建置信反馈循环；这不代表G6本身含有增强模块，也不是当前执行的初始化方案。用户随后明确选择先运行直接T1版本，并要求继承带增强的模型；当前采用完整K1权重。之后是否加入置信度、采用何种初始化，仍需依据本轮结果决定。置信度是候选交互机制，尚无本项目实验收益证据。

## 1. 已有证据与研究缺口

- G6是当前匹配系列中平均PSNR领先的强基线，但SSIM并非始终最高。新增模块和既有循环没有建立跨指标、跨划分一致的额外优势。
- 当前匹配K2三seed在test的同模型T2−T1图像PSNR平均为−0.012366 dB；这支持检查第二轮如何利用已有状态，不能唯一定位失败原因。[完整结果](TEST_COMPLETION_RESULTS_ZH_20261007.md)
- K1固定权重直接复用为P1＋T1图像反馈，188张test的PSNR从23.28481172变为23.26141203。它没有重新训练，不代表完整两轮联合训练失败。[复用报告](DIRECT_T1_REUSE_RESULTS_ZH_20261008.md)
- 当前直接T1图像反馈的两轮联合训练已完成：测试相对源K1均值略升，验证均值下降；同模型图像均值T2低于T1。该结果不支持把循环收益视为已成立，也不能在缺乏匹配追加预算K1对照时将变化独立归因于反馈。置信机制尚未实现或运行。

本次待检验假设：上一轮结果的局部可靠性估计，结合原始偏振观测，可帮助第二轮有选择地使用任务反馈，减少不可靠反馈带来的损害。此前实验没有证明局部错误传播是退化的实际原因。

## 2. 固定大框架与调用计数

符号：I为原混合RGB，P0为原始四角度偏振，E为偏振适配器，D为PolarFree任务网络，T1/T2为RGB透射估计，F1为第一轮任务内部特征，H为可靠性估计头。

```text
P0 + I → E → P1
I + P1 → D → T1、F1
原始偏振特征 h(P0) + I + T1、F1 → H → C1
P1 + T1 + C1（并保留原观测作为条件或回退信息）→ E → P2
I + P2 → D → T2
```

这版K=2指两次偏振更新、两次任务调用，不增加“先G6估计T0”的第三次任务调用。D每次仍接收原混合I；T1反馈进入E。两轮共享E/D参数，新增H是任务可靠性分支。优先复用已有特征和融合位置，不同时增加ConvLSTM、新主干或第三轮。

H依赖P0而不是只依赖被网络修改的P1，目的是保留观测依据。该选择是本项目设计判断，并不自动保证偏振真实性。

### 早期置信方案的模块与候选初始化（未执行）

|组成|职责|参数状态与初始化|
|---|---|---|
|偏振增强E|结合当前偏振和反馈条件，预测偏振残差|复用现有R2P编码部分，残差输出头零初始化；两轮共享并联合训练|
|PolarFree先验部分|编码条件并生成扩散先验|复用现有官方权重，参数冻结；保留训练所需输入梯度|
|PolarFree去反射骨干net_g|根据输入及先验生成T1/T2|加载同seed已训练G6的net_g权重，继续训练；两轮共享|
|可靠性预测H|由第一轮任务状态和原始偏振表示生成C1|新增轻量学习分支；局部可靠性辅助监督|
|特征对齐投影头组A|将增强模块融合特征映射到PolarFree内部特征空间|复用已有三组1×1投影与余弦对齐实现；作为可配置辅助训练分支|
|置信反馈融合接口|依据C1融合T1与原RGB条件特征，送入第二轮E|作为E内的接口复用共享编码；不另外增加一套完整恢复网络|
|固定偏振特征计算h|计算S0、DoLP及q/u等输入表示|复用现有预处理，无需学习参数|

G6是PolarFree去反射骨干的已训练权重状态，不是旁边另放一套G6网络。按核心网络计数，是E、net_g、H三块，此外还有特征对齐投影小头；按完整功能系统计数，是偏振增强、包含固定先验的PolarFree、置信度估计三块，另有对齐训练分支、融合接口与固定参数计算。此前只列三个主体的描述不涵盖全部训练机制。

零修改初始化的目的，是让正式方案在相同输入与同一扩散随机流下从G6输出起步，而不是先承受旧R2P的非零修改。该性质须在正式启动时核对，目前尚未实现/运行本版。G6使用同seed、预先指定的检查点，不按test挑选展示最好的seed。训练允许net_g与E/H共同适配；这个版本不同于此前冻结整个G6、只训练R2P的实验。

## 3. 置信度必须明确指代什么

本版C1(x)∈[0,1]表示第一轮T1在位置x附近的可靠性分数：高值预期对应较小的局部恢复误差。未经校准验证，不称作“预测正确的概率”。

必须区分：

|量|含义|不能直接推出|
|---|---|---|
|DoLP|观测光的线偏振程度|反射比例、T1正确概率|
|观测有效性|强度、饱和等对偏振特征可用性的影响|T1必然正确|
|C1|T1局部结果可靠性|该位置必须修改多少偏振|
|更新门控|任务网络学习的更新控制|真实反射mask或已校准置信度|

T1只有RGB三通道，不能直接从它求四角度测量意义的DoLP/AoLP。偏振特征来自P0。

PolarFree第4.1节定义了Stokes、DoLP/AoLP，且指出透射也具有偏振。RP2PN报告其数据中透射偏振常弱于反射，这是数据趋势，而不是所有场景的恒等规律。[R1][R2]

数学解释（本记录推论）：在线性、非相干加性混合且两层已包含到达传感器的衰减权重时，观测线偏振向量为sM=sT+sR，DoLP_M=||sT+sR||/(S0_T+S0_R)。不同方向的偏振贡献可以相互抵消，增加非偏振强度也会降低这一比值。因此不能固定设置C=DoLP或C=1−DoLP。暗部的分母较小会增加该比值对测量误差的敏感性；具体噪声影响仍需数据检查。

## 4. 首版输入和实际作用

候选偏振特征取原始P0的S0、DoLP及归一化Stokes分量q=S1/(S0+ε)、u=S2/(S0+ε)。q/u保留方向信息，避免直接把AoLP数值跳变当作普通图像边缘。该表示选择来自Stokes定义及其代数关系。[R1]

先复用项目已有偏振预处理。现有PolarFree适配器采用8位量化灰度、特殊零值处理并截断DoLP；由其计算的特征首先解释为与官方输入一致的数值表示，不能未经RAW线性化/标定核查就宣称满足严格测量物理模型。不得为新增分支静默改动官方任务输入。

首版优先让C1控制T1的反馈特征，而不直接用1−C1控制所有偏振更新：

```text
Z1 = C1 · f(T1) + (1−C1) · f(I)
P2 = clip(P1 + ΔE(P1, Z1, h(P0)), 0, 1)
```

f为两种RGB条件共享的编码路径；不同尺度下对C1做一致插值。高可靠位置更多使用T1，低可靠位置保留原观测条件。原I仍含反射，只是提供观测回退，不是干净答案。该具体融合是本项目待验证设计，不是文献已证明的最优结构。

已有R2P有RGB/偏振融合gate。本版的区别在于gate的依据包含可验证的任务质量估计，而不是仅增加一个名字为confidence的注意力层。

## 5. 如何训练和检验C1

最小候选监督：用训练集干净透射GT计算局部RGB绝对误差e1=LocalMean(|T1−GT|)，构造目标C*=exp(−e1/τ)。局部窗口和τ在训练/验证协议中预先确定，τ应说明与归一化RGB误差的尺度关系，不根据test调整。

C*只作为可靠性头的训练目标；生成目标时停止梯度，避免由该标签路径推动T1改变。可靠性辅助损失仅更新H：H的任务输入在该辅助分支停止梯度；正常的T1→第二轮任务反馈路径保留。联合任务损失更新E/net_g，冻结扩散先验参数并保留已有输入梯度协议。GT在推理时不进入H/E/D。

这是本项目提出的误差监督方案，并非声称直接复现UMRL。UMRL支持学习恢复置信度这一机制背景，其去雨结论不能直接迁移成去反射有效性。[R3]

两轮任务损失先复用当前匹配协议的[1/3,2/3]及傅里叶相位项系数0.1，避免同时改目标和交互。额外可靠性损失系数独立记录，只用训练/验证确定。

### 特征对齐分支的明确位置

现有aligned K1/K2已经有特征对齐。保存的`run_experiment_snapshot.py`中，R2P融合特征通过三组1×1卷积投影到96/96/192通道，再按对应PolarFree任务特征空间尺寸插值，计算三个尺度的平均余弦距离；目标任务特征停止梯度。目标来自第一轮PolarFree内部表示，不是GT图像、图像配准或GT反射mask。当前旧K2仅第一轮计算该辅助对齐，第二轮不计算投影。

本版保留并复用这条可配置训练分支，初始接口仍为第一轮多层对齐，不同时增加第二轮对齐或置信度加权对齐。是否启用及lambda_align必须写入正式配置；已有aligned系列的0.030651881051471687只能作为历史参考，不冒称它已针对新结构完成校准。用于判断置信增量的直接反馈/置信反馈对照须采用相同对齐设置。

完整训练目标可写为：L = (1/3)L_task(T1,GT) + (2/3)L_task(T2,GT) + lambda_align L_align + lambda_conf L_conf。当明确关闭对齐时lambda_align=0；不是默默删掉对齐机制。L_align直接训练投影头与增强模块，任务目标分支detach；任务恢复损失继续训练增强模块与net_g。置信度分支保持上文定义的监督与梯度边界。

特征反馈是将任务信息送入下一轮计算；特征对齐是训练时约束两种表示；置信度是估计T1局部可靠性并控制反馈。这三者目的与数据路径不同，不互相替代。

证据范围：旧对齐消融的收益随划分和指标改变，不能声称该分支已经稳定改善G6以上的结果。保留成熟接口与证明其有效性是两回事，仍须在新版中报告匹配消融。[完整test结果](TEST_COMPLETION_RESULTS_ZH_20261007.md)、[旧K1验证消融](K1_NO_ALIGNMENT_RESULTS_ZH_20261003.md)。实际实现见`server_scripts/normalized_threeway_20261002/reference/run_experiment_snapshot.py`的`feature_alignment_loss`与`forward_losses`。

可靠性验证：在验证集把C1按预定区间分组，检查高分组的实际局部误差是否更小，并记录误差排序相关性和不同场景的情况。不能只展示一张视觉合理的热图。任务梯度也会影响H，因此最终C1是否保有可靠性语义必须重新检验。

## 6. 主实验与必要对照

1. 主实验直接实现G6初始化＋两轮共享E/D＋偏振与任务可靠性H＋置信反馈融合，按完整联合路径训练。
2. 初始化、冻结范围、真实反馈梯度与有限数值的必要检查并入正式训练启动，不再把200/1000步小试验作为结构有效性的判定门槛或反复单独交付的主任务。
3. 保留同源G6继续微调的匹配额外预算对照。直接T1联合反馈用于后续消融，不能用旧K1固定权重复用结果替代它。
4. 后续固定常数图对照（同一分支、同样参数数量）与H去掉偏振特征的对照，分别检验空间可靠性和偏振信息的增量。
5. 主实验预算应根据训练预算核查扩大并记录学习曲线：原3000步仅约1.10遍训练帧；10000步为候选首个正式延长预算，再以验证趋势决定是否延长。具体配置在启动前记录，不将10000步称为已证明充分，不由test决定延长或选模。参见[训练预算核查](TRAINING_BUDGET_AND_DATA_COVERAGE_AUDIT_ZH_20261008.md)。

同时报告T2−T1、最终输出−直接反馈版本、最终输出−G6；报告图像与场景均值的PSNR/SSIM、退化场景、局部可靠性验证，以及实际时间和显存。相同步数不等于相同计算量。现有test已反复查看，只能作为探索材料；最终确认应使用未参与设计选择的评价数据。

若效果无正向线索，区分“C没有学会质量排序”“C有排序但融合方式无帮助”“偏振特征没有增量”，如实记录。收益和新颖性均尚未建立。
