## 1. 决定

优先研究“去反射网络的分层任务特征 → 第二轮偏振修正 → 原去反射网络”的闭环。原始RGB与偏振观测始终可访问；T1保留为第一轮结果和评价参照，不作为这一轮研究的反馈输入。不把I−T1命名为真实反射层或真实误差。

先以冻结第一轮、冻结去反射主干的条件化实验，检验任务特征是否比增强器自身特征的复用更有额外价值。第二轮仅通过偏振表示影响输出，暂不接预测C、Q、M或直接RGB残差修正头。关闭这些路径是为了限定新比较的研究问题，不是在已有证据上宣判它们全部无效。

这是一项更容易解释的候选设计，不是文献已证明优于T1反馈的算法。当前没有证据保证成功，也不把文献支持的通用组件当成新颖性证明。

## 2. 对历史的纠正

### 2.1 直接T1之前确实有任务特征反馈

2026-09-30方案将PolarFree三层特征分别投影到48通道、调整到同一空间尺寸后取均值，再经零初始化标量门注入轻量增强器。原始RGB固定，第二轮继续输入第一轮偏振结果；共享增强器和任务网络，两轮共同训练。

该版本没有一致收益：完整验证中，feedback相对no-feedback的逐图PSNR约+0.00221 dB、场景等权PSNR约−0.06667 dB，两个SSIM口径也更低。feedback自身T2−T1的逐图PSNR约−0.04497 dB。不能把旧方案说成已验证更好，也不能把后来的问题归责于用户提出T1输入。

证据：[历史两轮总结](JOINT_RECURRENT_EXPERIMENT_SUMMARY_ZH_20260930.md)；项目根run_experiment.py中的JointR2P与反馈前向。

### 2.2 近期代码已经有分层状态与观测锚点

复查第27项归档enhancer.py：已有两处不同层级的任务适配器、原始P0、当前P−P0及原RGB入口；但Tprev与Fprev被要求同时存在，预测图与I−Tprev、任务特征相加，并受到C调节。feedback.py还包含跨轮状态、对任务解码器的注入及最终RGB残差头。

因此，不能简单声称“现在改用多尺度特征/回看原观测”就是新方案。需要做的是把这些耦合路径拆成可检验的问题。旧输入约束也意味着仅把Tprev设为空会连带丢掉Fprev，不能作为干净的特征单独反馈实现。

证据：[第27项结果](polar_quality_matched_candidate_20261015/RESULTS_ZH.md)；源码快照位于../_dl/polar_quality_matched_candidate_20261015/artifacts/scripts/{enhancer.py,feedback.py}。

## 4. 待检验闭环

记原始偏振为P0、原RGB为I，第一轮增强器特征为A1，第一轮去反射特征为F1：

```
P0、I → 冻结的第一轮增强器 → P1、A1
P1、I → 冻结的去反射网络   → T1、F1
P0、P1、I、反馈状态 → 第二轮偏振修正器 → P2
P2、I → 同一冻结去反射网络 → T2
```

第二轮只学习相对于P1的有界偏振残差，始终保留P0与I的访问。新增输出从零起步，使P2=P1；在相同推理随机流下必须复现T2=T1。恒等起点只保证初始行为，不保证学习后单调改善。

只在已有两个对应层级使用轻量投影和局部残差适配，分别融合，避免先把不同层级压成一个均值。复用当前PIDSR衍生主干和浮点偏振入口，不更换骨干或成像处理。可训练部分限定为第二轮小型适配器及偏振残差输出头；第一轮和整个PolarFree参数固定，但第二轮任务损失仍可通过PolarFree对P2求导。

注意：现有旧适配器不能原样充当独立F接口，必须解除T/F同时存在的约束；旧预测、质量及RGB修正路径也不能暗中残留。以上是必要的最小适配，尚未实现。不得把多项删改与旧第27项横向相减，归因为“去掉T1的效果”。

## 5. 最小比较：两个训练组＋一个固定参照

核心假设：在相同观测、第二轮修正结构和训练预算下，下游处理后的状态F1能比上游自身状态A1提供更有用的偏振修正条件。

|路径|第二轮反馈状态|用途|
|---|---|---|
|固定参照|不执行第二轮，直接T1|核对额外阶段是否值得运行，无需另训一组|
|A：自身状态复用|第一轮增强器对应两层的A1|有相同修正结构、可学习容量和观测入口的主动对照|
|B：任务状态反馈|第一轮去反射对应两层的F1|检验经过下游处理的状态是否有独立增量|

这比只给A全零特征更能控制新增修正结构本身的学习能力。A也是任务训练过的增强器状态，不能称“完全任务无关”。比较回答的是下游推理加工后的特征是否额外有用，不是所有特征反馈对无反馈的完整证明。

归档中增强器两层宽度96/192，与任务接口两层96/192匹配，可优先复用同形投影；实际空间对应、数值尺度、填充和梯度仍需检查，不能仅凭通道数宣称完全可比。两组采用同一归一化规则、同一适配器形状及初始化。记录真实运算和耗时，不把相同调用数说成部署成本相同；A部署时可能省掉不用于反馈的第一遍去反射调用。

来源预定使用第27项所用第21initial共同起点中的第一轮部分，不选择第27项真实/固定任一训练终点。原来源SHA256在第27项报告可定位；执行时须在服务器重新核验。它有历史置信训练背景，因此新显式路径不使用C，不等于从未见过C的训练历史。

两组复用同一恢复损失，不新增对齐、质量、可修复性或接受损失。来源中的既有单轮能力被保留，不把固定的历史对齐过程说成此轮验证出的贡献。

## 6. 预定筛查与停止规则

先完成训练内的接口和数值检查，再锁定独立新运行协议。计划各2000步、同seed、同数据/裁剪/随机流与优化器设置，固定终点评价。2000步是资源受限初筛预算，不是充分收敛证明；来源路径、可训练清单、修正上限、学习率和GPU截止须在启动协议中锁定。没有锁定前不启动训练。

复用已登记的64张验证清单，8场景各8张，完整原尺寸，不读取测试选方案。主比较为B−T1和B−A；并列报告场景等权PSNR/SSIM、逐图变化与所有负面场景。不得将64帧当64个独立场景。

为避免再次靠极小正数自动延伸，预设本轮资源筛查门槛：两个主比较的场景等权PSNR均至少+0.05 dB，场景等权SSIM均不下降，并且两个比较分别至少6/8场景PSNR正向。此数值和场景数是本项目的保守投入门槛，不是文献规定、统计显著性标准或通用有效性阈值；正式执行前登记，不能看结果后放宽。未过门槛只表示不继续投入本实例，不否定整个特征反馈家族。

结果对应决定：

- B超过A但未超过T1：任务状态可能减轻了损害，第二轮仍无净价值，不扩展本版本。
- B超过T1但不优于A：额外修正阶段可能有价值，任务反馈的额外必要性未成立，不恢复C线。
- 两项都过预定门槛：只安排锁定配置的完整872验证＋188测试及匹配重复确认，之后才考虑是否值得研究C；小样本单seed不称稳定有效。
- 两项都未通过：保留负面结果，结束本实例，不自动延长训练、追加循环轮数或换新门控。

若在正向结果后做同权重的状态错位干预，仅作为空间依赖的补充诊断；它不能替代独立训练对照，不据此反复挑模块。
