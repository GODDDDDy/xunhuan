## 5. 统一数学定义，避免再次混淆标签

设T1是固定第一轮，U是固定候选，delta = U - T1，G是训练/评价GT。动作集合固定为：

    actions = [0, 0.25, 0.5, 1]
    T(a) = T1 + a * delta
    true_cost(a) = mean_region_RGB((T(a)-G)^2) - mean_region_RGB((T1-G)^2)

这里使用原始浮点RGB和既有官方评价一致的MSE定义，不能从8位PNG重建标签，不能擅自clamp后再与旧未clamp标签混用。4×4平均、边界、padding和图像尺寸以已有实现为准。

- 成本小于0表示改善；收益等于成本的相反数。
- 0动作真实成本和预测成本固定为0，不增加一个可训练的“拒绝成本”。
- 三个非零动作真实成本分别计算，不用a乘全幅成本替代。
- T2 = where(M == 0, T1, T1 + M * delta)，M按4×4区域最近邻扩展。
- M为0的位置必须逐元素严格等于T1。
- coverage = 被修改的像素/区域面积比例；mean(M)是平均幅度，不是覆盖率。
- 接受集为空时，有害接受率写null/NA，不能写成判断准确率100%。

给归一化尺度s > 0，当前loss与对照loss：

    y = true_cost(nonzero_actions) / s
    L_fit = SmoothL1(predicted_cost, stop_gradient(y))
    p = softmax(-concat(0, predicted_cost))
    L_policy = mean(sum(p * stop_gradient(true_cost(all_actions) / s)))
    L_mixed = L_fit + 0.1 * L_policy
    L_pure = L_fit

正式单因素比较只改变上述0.1项是否存在。不要同时改特征标准化、动作尺度、输出结构、损失权重、初始化或门槛规则。

数学核对：

    e = T1 - G
    A = 2 * mean_region_RGB(e * delta)
    B = mean_region_RGB(delta^2)
    true_cost(a) = a*A + a^2*B

B是可观测量，A含GT，仅能构造监督/评价标签。结构化A/B预测是后续备选研究问题，本轮不一起加入。

**结论限制：** 两个MLP都拟合差，只说明所用探针/预算/表示没有拟合好；不能直接判定原生模块坏。MLP拟合好，也不能证明具有空间卷积的原生判断器已经解决。

## 8. 阶段A2：原生卷积判断头的小样本匹配诊断

目的：真正检查当前原生判断头能否学习，而不是用线性/MLP成功替代原生网络成功。

### 8.1 构造与冻结

1. 按已核验第22项架构构建50输入通道的原生模型，再严格加载第22最终权重。
2. 不可把50通道权重再次交给“额外扩7通道”的迁移器，造成57通道；也不可先用43通道结构严格加载50通道权重。复用定义时先核对构造顺序。
3. 创建两份完全相同的action_gate副本，分别训练L_mixed和L_pure。开始前所有头张量严格相等，源SHA一致。
4. 所有非action_gate张量和整个任务网保持来源严格相等；eval与requires_grad=False都设置，不能仅调用eval就声称冻结。
5. action_gate.feature_projection属于可训练判断器。其他任务特征、状态、H、Q、反馈、候选和先验不更新。
6. 本阶段不加入标准化层、不换输出参数化、不改变50通道含义、不重初始化输出层。唯一训练因素为loss。

### 8.2 生成最小空间缓存

不能使用A1的散点NPZ假装空间缓存。使用原scheduled_loader的数据/裁剪逻辑，在训练角色中固定取：

- 判断角色12个场景，每场景2个128×128裁剪，共24个训练裁剪。
- 偏差角色4个场景，每场景2个裁剪，共8个。
- 安全角色4个场景，每场景4个裁剪，共16个。
- 选择sample_id和裁剪坐标前不读GT或结果；优先按sample_id固定hash排序，均匀选图，固定裁剪随机种子。
- 独立保存48个样本的角色、scene、sample_id、原图尺寸、裁剪坐标、增强参数和随机流标识。

一次冻结两轮前向提取每个裁剪的：

1. 由冻结网络生成的T1、U、delta、b、C、judgement_state。
2. 判断器feature_projection之前的原始judgement_feature。
3. 原RGB及偏振摘要需要的4×4池化结果。
4. 三个非零真实成本，以及在本阶段共同尺度s下的归一化标签。
5. 4×4增量平方均值、绝对均值、抵消比例。
6. 完整32×32邻接关系；不能只保存随机区域。

主干只运行一次。优化判断头时，每次重新通过该头自己的可训练feature_projection；不得缓存投影后的8通道后再宣称projection得到了训练。

FP32可无损容纳已经生成的BF16数值，但头运行的autocast设置必须和在线路径一致并通过等价核验。不能为了缓存方便改成FP16、量化、clamp或PNG。若构造缓存函数，最少复用FloatActionCostGate.inputs逻辑，不另写一个含义相近但不同的版本。

### 8.3 必须通过的缓存等价检查

在固定5个裁剪上比较在线和缓存路径：

- 初始头的三个成本输出一致。
- 同一loss数值一致。
- 同一优化步的feature_projection及body梯度一致。
- 从相同权重、优化器、RNG做一次更新后头参数一致。
- 非判断张量仍严格相等。
- GT替换改变标签但不改变缓存的可部署特征。
- M0严格复制T1。

先尝试确定性FP32的严格一致；若设备/算子造成小数差异，预先声明容差、记录最大绝对/相对误差及原因，默认输出/梯度allclose阈值atol=1e-6、rtol=1e-4。哈希不等但数值等价的情况必须如实区分，不把allclose写成逐比特一致。不通过则停止优化，修复后重做。

### 8.4 小样本优化

- 共同来源为第22最终action_gate，Adam lr1e-4、有效batch2、微批1、梯度clip_norm=1。
- 两头使用同一24裁剪循环顺序、相同500步、相同随机流与初始优化器状态（新的空状态）。
- 只训练原生头及其projection；不增加从GT生成的输入特征。
- 初始化、每100步及500终点记录纯L_fit和三动作排序；每步记录真实lr、梯度、有限值、样本ID。
- 固定500终点，不选择最佳监测点，不因某头领先就提前停止另一头。
- 若出现NaN、梯度流到冻结部分、缓存等价失败，属于执行失败，保存证据；不能当机制负面结果。
- 分别记录“训练拟合是否下降”“是否优于训练均值预测”“跨场景是否保持”“实际排序是否优于随机”，不靠单个总loss判断。

这是24裁剪的原生头学习性诊断，不是覆盖1140图的正式3000步实验，也不证明收敛。两头受相同来源历史影响，检验的是来源上继续优化的目标差异。

### 8.5 诊断级偏差与安全筛查

- 尺度s沿用核验的第22来源尺度，两个诊断头相同；不分别按其输出重设尺度。
- 两头分别在相同8个偏差裁剪估计偏差，在相同16个安全裁剪跑同一旧门槛网格。
- 网格为0、0.05、0.1、0.2、0.4、0.8、1.6、3.2、6.4、12.8；实际单位为归一化成本。
- 仍要求平均MSE不增且接受明显有害区域比例≤20%，从合格项选最大覆盖；明显有害间隔为0.02*s。
- 没有合格非零覆盖则拒绝全部；同时safe=true、useful=false，接受有害率写NA。
- 这只是小样本诊断校准，不能部署、不能声称获得总体安全保证。B必须使用完整原训练内角色重新校准。
- 不根据A3验证结果更改偏差、网格、尺度或规则。

## 9. 阶段A3：最多32张原尺寸验证筛查

### 9.1 预先固定名单

从已有manifest的8个validation场景取每场景4张，最多32张。按sample_id固定顺序取覆盖序列的四个位置，例如排序后索引floor(j*(n-1)/3)，j=0,1,2,3；若场景不足4张则取全部且去重。

名单、manifest SHA和选择规则在读取这些图的GT与性能之前锁定。不能选“容易出现收益的图”或避开负面场景。该集合是已被历史探索的代表性筛查，不是独立确认集。

### 9.2 一次原尺寸主干前向，评价多个头

每张图只执行一次冻结主干，得到共同T1、U、原始任务特征与状态；源头、mixed诊断头、pure诊断头依次作用于同一组特征。

- 只构建一个完整主干，另建小判断头副本；不要加载三套PolarFree。
- 每个头使用自己训练内得到的偏差和门槛，不能复制另一个头的校准数值。
- 复用官方PSNR/SSIM函数，分别计算源、mixed、pure的真实拼接输出。
- 保存每张T1和U浮点哈希，按sample_id与第22来源记录匹配；不能只按列表位置关联。
- 保持原尺寸完整前向，不切块、不缩小后宣称整图评价。
- 不重复normal/guidance_off/Q0/Q1/no_feedback/no_polar_correction整套干预。
- M0等价检查已经在预检做完；本轮研究loss，无需重做全部不相关机制诊断。

记录每头的三动作成本MAE/Spearman、T2-T1 PSNR/SSIM、按场景差、覆盖与幅度、误接受/误拒绝、固定示例。接受集为空时仍记录门控前成本排序，避免全零遮盖问题。

### 9.3 A阶段结束时的结论模板

必须给出以下各项，使用“支持/不支持/证据不足”：

1. 数值目标与标签是否正确。
2. 散点表示是否有可拟合信号。
3. 原生头在固定小样本上是否能学会。
4. 去掉期望项是否改善纯成本拟合与实际收益排序。
5. 换训练内场景和原尺寸32张后是否保持。
6. 是否找到符合预定条件的非零修改，还是仍全拒绝。
7. 与额外容量、继承历史、小样本、未收敛有关的限制。

可建议进入B的信号：pure在固定终点的拟合优于mixed/简单基线，安全角色选择净改善为正且好于同覆盖随机期望，4场景至少3个方向为正，原尺寸筛查未出现明显相反趋势。这里只形成下一阶段建议，不自动启动B，也不把32张结果写成全验证成功。

若都学不好：先报告训练条件/输入/目标尚未解决；不得直接宣布置信模块理论无用。若训练拟合好但跨场景失败：优先定位泛化/上下文问题。若pure更好：只能说混合目标可能有贡献，正式确认仍需B。

阶段状态使用diagnostic_complete；不使用formal_experiment_complete。

## 10. 阶段B：获授权后执行正式的单因素匹配对照

此阶段用于确认A的信号，不默认执行。若A缺少关键有效性检查，先处理问题，不能绕过它直接跑更多步。

### 10.1 两个分支与共同条件

    B0_control: L_mixed = L_fit + 0.1*L_policy
    B1_treatment: L_pure = L_fit

每分支3000步固定终点，首轮seed2026；正式启动前将两分支步数、资源上限和评价预留写入新locked_run.json。初始权重都严格等于第22最终，优化器/RNG新建；没有一支额外热身或先接受另一支更新。

共同保持：原50通道输入、原生卷积头、可训练feature_projection、Adam lr1e-4、clip_norm1、有效batch2、微批1、crop128、动作集合、4×4区域、候选/第一轮/所有非判断权重冻结、数据角色、采样顺序、校准算法、评价实现和seed策略。

**禁止在B1同时加标准化、结构化A/B输出、新Q监督、不同成本尺度或新动作。** 若A证明必须先修改其中一项，应另立该项的单变量计划，而不是继续称本轮只改loss。

### 10.2 数据与校准

沿用完整角色：

- judgement：12场景、1140图，正式训练均覆盖。
- bias：4场景、237图，仅估偏差。
- safety：4场景、423图，仅按预定网格选择门槛。
- candidate：31场景、3640图，本轮不更新候选，不把它们写成判断训练图。

成本尺度按原规则从相同判断训练256裁剪计算一次，两个分支共享；禁止各自从验证/测试估尺度。每个头自己的偏差和最终门槛可以因训练结果不同而不同，但算法、数据和条件必须相同。

上游随机性固定为来源定义：相同sample_id、裁剪、增强、阶段随机流产生相同T1/U。优化器随机种子与上游推理随机流分别记录。不同头seed实验不得悄悄改变冻结候选的扩散噪声。

### 10.3 训练与终点

- 可以预生成共同6000训练裁剪的冻结上游缓存（3000步×有效batch2），两个头共用；严禁缓存可训练projection之后的输入。
- 初始、1000、3000步做固定训练内小监测即可，不再每500步完整重复主干探针。
- 非判断参数在开始与结束逐张量严格核验；中途做轻量检查。任务网436张量也需保持来源。
- 每分支保存1000/2000/3000检查点可供恢复，评价使用3000终点，不根据验证/测试挑点。
- 若资源截止不能完成3000，标记training_incomplete；不能用最后保存点冒充预定完整对照，也不能延长原预算。
- 训练监测不能自动调整lr或追加步数。

### 10.4 完整评价要求与节省方式

两个正式分支都必须获得完整872验证、188测试，逐图与场景PSNR/SSIM、候选/T1/T2、各非零动作预测/实际收益、覆盖/损害、失败记录。

由于只改变小判断头，**可以共享冻结主干的完整前向**：每张图一次原尺寸主干执行，在同一T1/U及特征上依次运行两个头，分别拼接并计算真实整图指标。这仍是两个分支各自的完整评价，不是少测或使用旧T2代替。

先用5张固定图核验共享前向评价与各分支独立在线评价等价，明确数值容差与随机流。训练期最后更新的projection必须在评价时实际使用。不能只加载两个body却共用其中一个投影。

不重复872来源潜力诊断、GT理想选择或不相关28×8干预。既有T1/U统计在哈希、随机流、评价配置核验一致后可作为参照复用，但新T2必须实际拼接评测。

单seedB完成仍只支持当前起点和预算的对照。若要宣称稳定，需要在正式结果出来前或新的用户授权中预定重复种子；建议2026/2027/2028。每个正式seed保留完整测试，不根据188结果选择是否继续或挑seed。

### 10.5 比较指标

主问题：B1是否比B0更准确地估计成本并更可靠地选择有益修改。至少记录：

1. 独立训练内场景与完整验证的三动作成本MAE、排序相关。
2. 完整验证T2-T1 PSNR与SSIM，场景等权与图像等权分别报。
3. 覆盖、平均幅度、实际净MSE改善、明显有害接受及有益拒绝。
4. 与B0相同数据上的配对差，不只看B1相对T1。
5. GT理想选择仅作为既有上限参照，不列为可部署成绩。
6. 188测试只作锁定方案的结果报告，不反过来取消门控或改训练。

区域/同场景连续帧相关，不能把数百万区域当独立重复。重复seed和按场景报告；若做置信区间，优先按场景重采样并说明只有8个验证场景，估计不确定性较大。不通过这些检查不能宣称统计显著。

## 11. 阶段C：获授权后检验模块协同，不能靠推理关开代替

此阶段与A/B不同：要改变候选机制并分别训练。不能把A/B只训练判断的结果解释为证明跨轮状态、Q或质量反馈的全部因果价值。

### 11.1 先只选一对可分别启用的因素

推荐的第一对：

- 因素A：候选生成中，用预测C动态调节第一轮参考；关闭时对应参考加权系数固定为1。
- 因素B：第一轮任务特征直接传入第二轮候选状态/适配/纠错头；关闭时这些直接任务特征通路置零。

这些定义分别检验“动态参考加权”和“直接任务特征传递”，不是一次删掉整个质量头或整个跨轮状态。两轮执行、原P0/RGB、浮点桥、T1观测、偏振特征和基础纠错支路四组均保留。

尤其注意：

1. 不得把no_feedback干预中整个Z清零直接当B关闭；那会同时删除原始观测、多个特征和质量信息，不是单因素。
2. A只控制候选中的参考调制；判断器四组均可读取同一真实H输出C，避免同时改变判断输入。
3. 质量H保持同一冻结预测器，不在不同组重训不同H。Q/三级Q注入在四组采用同一种预先锁定设置，推荐关闭注入，防止第三因素参与。
4. 执行前画出所有受控路径，列出文件/函数、张量和开关。B关闭不能删除H计算自身所需的第一轮特征。
5. 若A或B关闭后另一因素完全没有作用通路，则两因素不是可独立检验的设置，先修订定义而不是硬凑四组。

### 11.2 四组正式训练

|组|动态参考A|任务特征传递B|
|---|---|---|
|C00|固定参考权重1|关闭直接任务特征|

同一seed下四组公共参数、允许的第二轮专用初值、batch/crop序列、GT标签定义、训练步数、lr、判断阶段、校准及评价都匹配。关闭路径可以保留同形状模块但置零输入，并报告活跃容量差异；额外参数的影响并不自动消失。

第一轮全部冻结，候选训练只更新第二轮专用模块。正式执行前必须锁定各组候选和判断步数及新预算；短pilot可以讨论候选3000、判断1000，但这个数字不是已授权的新运行，不保证收敛，不得直接套用判断0.34秒/步估计有主干反传的候选训练。

不同候选不能共享第二轮的原始特征或成本标签。可以在严格等价核验后共享完全冻结的第一轮，但第二轮仍各自执行。每组每个正式seed均需完整872验证和188测试；先单seedpilot，稳定性确认另预定重复seed。

### 11.3 观察协同，不让全拒绝掩盖候选变化

预先报告两层结果：

- 候选层：U相对共同T1的实际MSE、PSNR、SSIM、场景差及局部副作用。
- 最终层：每组经过同算法训练和校准的判断后的T2、覆盖、净改善及损害。

最终都拒绝全部时，只能说部署层没有收益；候选层的差异仍需保留，不能说所有机制都没有作用。若只有GT理想选择提高，说明潜力存在，不能证明实际部署协同成功。

对同一指标Y、同一划分与权重计算：

    A在B关闭时的贡献 = Y10 - Y00
    A在B开启时的贡献 = Y11 - Y01
    B在A关闭时的贡献 = Y01 - Y00
    B在A开启时的贡献 = Y11 - Y10
    interaction = Y11 - Y10 - Y01 + Y00

Y若取误差则改用负MSE，使越大越好；若取PSNR则所有项均用同一种平均口径。不要把MSE提升与dB提升混加。正interaction是相对于该指标和基线的交互，不能自动证明物理机制或模块组合总体成功。

- 两单独组不改善，组合重复改善，且interaction方向稳定：支持协同。
- A改善、加B无额外改善：B在此设置下未显示额外贡献。
- 加B反而下降：存在当前配置的副作用或训练冲突，仍需定位原因。
- 四组都不改善：只能说这一实现/数据/预算未有效，不能断言理论无用。
- 对泛化和稳定性的结论，需要按场景及seed重复；不能根据一次极小正值宣布协同。

Q与其注入器是功能耦合单元；单独Q没有影响图像的通路，不能据此判Q无用。以后检验该单元时，比较同一注入器上的预测Q、固定Q、关闭注入，并考虑等容量控制；那是另一项预定问题，不在本轮同时加入。
