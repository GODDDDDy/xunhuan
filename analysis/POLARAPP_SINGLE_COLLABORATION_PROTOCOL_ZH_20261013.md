## 2. 原始依据与适配边界

原始研究：Luo等，*PolarAPP: Beyond Polarization Demosaicking for Polarimetric Applications*，arXiv:2603.23071v2。[论文第3节](https://arxiv.org/html/2603.23071v2)。官方代码固定提交为 `1f2b4b86eb8e2b3a863a7fb53162b87fac5a3860`：[训练器](https://github.com/roydon-luo/PolarAPP/blob/1f2b4b86eb8e2b3a863a7fb53162b87fac5a3860/DfP/polarapp/trainer.py)、[FANet模块](https://github.com/roydon-luo/PolarAPP/blob/1f2b4b86eb8e2b3a863a7fb53162b87fac5a3860/DfP/utils/utils_net.py)、[公开权重](https://huggingface.co/Roydon728/PolarAPP)。

官方机制以内层可微的上下游临时更新，检验外层重建/任务目标，并由混合二阶导数学习对齐度量；随后固定度量权重，以对齐和任务目标进行真实联合更新。本次保留这条计算路径，而非仅用更大卷积网络替换固定相似度。

以下均为本课题的适配，必须与原文事实区分：

- 本组为同分辨率偏振纠偏，没有照搬官方CPFA成像、两倍分辨率重建、EIT与后续refinement全流程。
- 官方上游第一尺度96通道，我们为48通道；首尺度48→96接口继承来源P1投影，空间按照任务特征的实际尺寸匹配，不能机械保留官方两倍插值。
- 增强侧目标为保持冻结来源单轮偏振输出的MSE代理，**不是干净偏振GT、真实偏振物理误差，也不是EIT**。它可能保留来源缺陷或限制有益纠偏。
- 参数高效适配、训练数据角色划分、保持系数、梯度比例校准及数值缩放是待验证的研究选择，原文并未证明本组合有效。
- 元学习训练迭代不是推理时循环；部署图始终只增强一次、执行任务一次。

## 4. 参数分组、目标与更新方式

|分组|独立可训练参数|更新规则|
|---|---:|---|
|增强侧三尺度新适配器|11,136|两分支真实joint均学习，Adam lr=1e-4|
|任务侧三尺度新适配器|12,720|两分支真实joint均学习，Adam lr=1e-4|
|FANet约定子集及首尺度特征接口|2,001,408|仅meta阶段学习，Adam lr=1e-5，epsilon=1e-8|
|增强主干、既有输入适配、PolarFree主干与先验|0|冻结并eval；保留对输入的梯度|

FANet连同接口共8,471,040个独立参数；总登记参数还可能包括不参与前向的官方教师与历史支路。总登记参数、活跃参数与可训练参数分别记录，不混用。真正的部署前向不包含FANet。

固定目标：

```
L_task = mean((Y - GT_RGB)^2) + 0.02 * RGB边缘MAE
L_keep = mean((P - stop_gradient(P_source))^2)
L_outer = L_task + 0.1 * L_keep
control: L_joint = L_outer
meta:    L_joint = L_outer + lambda_FA * L_FA
```

`P_source`由冻结来源单轮模型和部署可用输入产生；不是理想偏振真值。两个分支采用相同目标的任务/保持部分。GT只用于训练监督和评价，不进入部署输入、状态、随机噪声或FANet的推理替代路径。

Meta每次内层对上下游适配器执行一个步长1e-4的**可微临时更新**，临时参数不写回原模型；外层使用不同训练角色样本计算目标，由 `create_graph=True` 和功能式调用保留混合二阶路径，仅更新FANet约定参数。Joint阶段FANet参数固定，但不能对FANet调用包 `no_grad`，否则会切断上下游对齐梯度。

固定元学习数值单位为 `1000 * L_outer`，内层FA与真实joint目标不乘1000。它是针对准备阶段FP32/Adam epsilon量级的数值修订，同时缩放task与保持项，保留目标相对权重和梯度方向，但不保留Adam轨迹、不提高信噪比、不证明有效性。正式预检记录raw/scaled超梯度、FANet相对L2更新、虚拟输出有限性；不得以仅“非零梯度”代替实际可学习量级核验。

FA系数仅在8个预定训练裁剪上校准：逐裁剪计算任务/保持联合梯度与FA梯度的相对规模，目标比例0.1，上限0.1，下限0；有效有限值按中位数得到一次性系数。实际规则、有效样本数、量级及最终系数写入锁定收据。若FA梯度无效、零或不满足路径核验，预检失败；不借验证或测试重新选系数。Control始终lambda=0。数值校准和速度可行性确认之后才锁定正式协议。
