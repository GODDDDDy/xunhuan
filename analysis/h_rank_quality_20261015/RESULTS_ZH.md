# H局部排序增强：匹配初筛结果

2026-10-15。结论：已实施并完成一次基于文献的H增强尝试，但显式局部排序项未显示明确的同预算增量。保留原H，停止本次候选，不追加系数搜索、不启动872/188完整确认。

这不是“H无法增强”的结论，也不否定已有质量排序能力。本项只回答固定第一轮、现有H结构、当前2000步继续训练条件下，这一项排序约束是否值得继续投入。

## 1. 实施方法与依据

借鉴Moon等ICML2020的[Correctness Ranking Loss思想](https://proceedings.mlr.press/v119/moon20a.html)，以及Liu等ICCV2017 [RankIQA的成对hinge排序](https://arxiv.org/html/1707.08347v1)。两篇原研究分别针对分类置信度、整图感知质量。本项目将监督改为同图局部RGB恢复误差，保留原mean(e/b+log b)，增加0.1倍局部log-error排序项；不是对原论文去反射结论的复现。

不改变H结构、输入、b/C定义和推理成本。固定第21initial的第一轮、增强器、PolarFree及全部循环接口，仅更新H的两份副本。两组同起点、独立新Adam、同4000张训练图的128裁剪、各2000步；每个裁剪共用同一个冻结第一轮前向。未覆盖剩余1440张训练图，不称全训练集遍历或充分收敛。

对照A用原损失继续训练；候选B在同预算上加排序。另评价未经此次续训的原H，区分额外训练与排序约束的贡献。GT仅用于训练误差标签和评价，未进入H前向。原H、源模型和上游权重均保持原样。

B相对同预算A：

- AUSE **上升0.000511**，排序筛除表现略差；预设要求至少下降0.005。
- 只有**4/8场景**AUSE改善，未达到至少6/8场景的门槛。
- Spearman增加约0.000629，最差20%召回增加约**0.0212个百分点**，均非常小。
- b的MAE增加约0.000148；原尺度损失上升0.004394，虽然没有超过预设0.02容忍值，但没有数值拟合改善。

B相对原H的Spearman增加约0.008718、召回增加约0.7012个百分点、AUSE下降约0.002182；然而A也有类似改善。因此不能把新B对旧H的差异全部归因于排序项。原H的尺度损失和b的MAE还略优于两个续训终点，不据此把A当成已确认的新模块。

这些是同一探索验证集上的描述结果，单seed、相关帧、小幅变化，不宣称统计显著性或跨模型稳定性。

## 4. 评价定义与边界

AUSE采用移除预测最差区域后、剩余区域MAE除以原图平均MAE，与GT理想排序的曲线差，在移除0至0.95（步长0.01）积分。参考Ilg等ECCV2018 [排序筛除评价](https://arxiv.org/abs/1802.07095)，但此处是明确指定的局部MAE归一化版本，不能与其他任务AUSE数值直接比较。理想排序AUSE为零的检查通过。

最差20%召回：取预测误差最大的20%网格位置，检查覆盖真实误差最高20%的多少位置；真值阈值并列全部纳入。当前64图未造成precision/recall数值差异。

这是启动前登记的探索初筛，完整64张原尺寸均已完成，不缩图、不分块；**872验证及188测试未运行**。没有利用测试调参、挑权重或选择是否继续训练。第29项初筛完成，不称正式完整确认完成。此项没有第二轮前向或恢复增益评价，不影响已有两轮参照的原始结果。
