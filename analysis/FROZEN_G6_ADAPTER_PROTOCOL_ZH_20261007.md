# 固定已训练 G6、只学习偏振适配器：执行协议

## 问题与范围
检验：net_g 已经完成普通微调后，保持整个 TaskNet 不变，只学习前置偏振修改，能否在固定验证协议下获得额外增量？这是分阶段可行性实验，不等同于旧联合模型的单因素消融，也不能据此直接判定模块结构或循环思想正确与否。

## 预先固定的执行方式
- 对应使用 G6 seed 2026、2027、2028 的 step3000 检查点，冻结 TaskNet 的全部参数与缓冲区。
- 采用现有自定义 R2P，保留 e42 预训练特征部分，将最后残差输出卷积的权重和偏置置零。初始偏振修改必须严格为零。
- 不计算 alignment，不更新投影或反馈模块，关闭反馈，一轮前向。训练中只有 18 个 R2P 参数张量获得 Adam 更新。
- 每组额外训练 3000 步，沿用原训练日程、batch=2、crop=128、R2P 学习率 1e-4、Adam (0.9,0.999)、无 weight decay、梯度裁剪 1。任务损失沿用 L1 + (1−SSIM) + 0.1 相位损失 + 0.1 VGG 损失。
- 先做梯度与初始化检查，训练至 200 步核查后恢复至 3000 步。采用固定最终步，不使用 best.pt 选择。
- 每组对同一 872 张探索性验证集评估，推理随机种子固定为 2026；本轮不增加 test 或循环结构。

## 必须通过的审计
1. 初始训练裁剪输入、28 张全分辨率代理输入均验证零修改；直接 G6 与带零修改适配器的输出按同一 CPU/全部 CUDA 随机流对照。
2. 代理图以它在完整验证列表中的原索引恢复随机种子，与历史 G6 逐图 PSNR/SSIM 对照（容差分别 1e-5、1e-7）。初始输出对照容差 1e-4，输入差必须为零。每组 28 张通过后复用历史 872 张 G6 基线；不声称重新评估了完整 step0 基线。
3. 梯度确实传到偏振输入和 R2P，但 TaskNet、投影、反馈模块无梯度。零头初始化下第一步仅输出头获得非零梯度是预期现象。
4. 每次保存对全部冻结张量做哈希核验；200/3000 步核验 net_g 与对应原 G6 逐元素相同、只有 R2P 的 18 个 Adam 状态更新、训练日志连续且有限。
5. 锁定代码、配置、输入清单、训练日程、初始化权重、源 G6 检查点和指标哈希，保留日志与失败记录。

## 解释边界
源 G6 已训练 3000 步，本轮另增加 3000 步 R2P 更新，且重复使用原训练数据日程。主要比较是适配后的输出减去同一个冻结 G6 的输出，不能作为相同总训练预算的模型排名。零头重置改变了 e42 原模块的初始化；本实验同时采用已训练 G6 和分阶段训练，不能将差异单独归因于初始化或冻结。

三组源 G6 本身不同，因此三组差值包含源模型与适配学习的变异；不足以单独估计适配器种子噪声。验证集已被此前实验分析过，结果属于探索，不能称独立确认。推理采样变异未估计。

最终报告同时给出 PSNR/SSIM 的图像均值与场景宏均值、三个配对差值及样本标准差、场景与 easy/hard 描述性分组，保留负面结果。不得以微小差值声称噪声内、等价或显著；不得以 PSNR 单项上涨称画质全面提升。

## 方法来源与区别
复用本项目原数据、模型与训练实现。此处冻结 G6 后训练偏振适配器是基于已有消融结果提出的待验证方案，不是文献已证明的收益。PolarAPP 的联合学习/任务驱动精炼可作为背景，但其元学习特征对齐与本项目普通投影余弦损失不同；PIDSR 的空间尺度递进与本项目同尺度前置模块也不同。
