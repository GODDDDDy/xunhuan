## 研究重点与当前判断

偏振增强是必须保留的研究方向；循环/上一轮反馈希望取得实际增量；置信度只是可选辅助。评价的是对去反射结果的净收益，不以增加模块数量作为贡献。

- **强G6是后续方法研究的参照。** seed2027 step3000按完整验证表现选择，没有按测试最高挑选。它与继承第18项联合模型的旧一轮不是同一来源。
- **H在对应一轮上有质量排序信息，但没有证明当前系统能把它变成稳定恢复收益。** 第30—33项包含完整872验证/188测试、预测/常数/GT质量条件对照；不能把失败全归给H，也不能断言所有二轮没有空间。
- **现有增强与反馈候选尚未建立超过G6和匹配普通续训的净收益。** 第38—41项逐步检查续训、Adam与实际路径依赖，结果只约束所测试配置。
- **第42/43项是另一条来源明确的单轮分支：原配PolarAPP重建后再做任务感知增强。** 它不加载G6，不使用循环或置信度图，不能把其结果直接称作G6上的改进。
