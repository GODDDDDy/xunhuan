## 3. 必须通过的缓存等价检查 → **通过（逐比特相等）**

`receipts/online_cache_equivalence.json`，5 个固定裁剪、FP32、未开 autocast、atol 1e-6 / rtol 1e-4：

| 非判断张量仍严格等于来源 | 是（0 个不匹配） |

| M0 严格复制 T1 | 是 |
| 梯度裁剪范数 | online 0.9491429925 = cached 0.9491429925 |

**结论是逐比特等价，不是因为容差放宽而"看起来相等"。**

> **执行陷阱（已记录并修复）**：冻结双轮前向经 `set_step_seed` 对随机数流敏感——
> 外来 (phase, step, sample) 三元组会让 T1 变化 0.017～0.021。
> 因此缓存必须以生成时同一三元组重放，且 `set_step_seed` 与 `recurrent_forward` 之间
> 不得插入任何消耗全局 RNG 的调用（如 `torch.rand_like`）。该敏感性本身也已写入回执
> `rng_sensitivity` 字段作为证据。

## 5. 唯一训练变量的效果：期望项无收益

- 终点 L_fit：pure 比 mixed 低 **1.40e-04**（0.127553 vs 0.127693，相对 0.11%）——**pure 略好**。
- 排序、偏差、跨场景 MAE 全部同级（见下表）。
- 筛查结论完全相同（都是拒绝全部）。

→ 去掉期望项（0.1·L_policy）**没有损失**，也没有可测得的收益；
mixed 相对 pure 的唯一系统性差别是"略微更差"。

## 8. A 阶段结论模板（支持 / 不支持 / 证据不足）

1. **数值目标与标签是否正确** → **支持**：A0 通过；A2 缓存等价逐比特通过；GT 替换只改标签不改可部署特征；M0 精确复制 T1。
2. **散点表示是否有可拟合信号** → **证据不足（弱）**：A1 MLP 训练内可拟合但不迁移，选择性修改无净收益。
3. **原生头在固定小样本上是否能学会** → **支持**：L_fit 下降 8.4%，MAE 优于两个平凡基线，训练内 Spearman ≈ 0.24–0.27。
4. **去掉期望项是否改善纯成本拟合与实际收益排序** → **不支持**：pure 与 mixed 同级（终点 L_fit 差 0.11%），排序差 ≤ 0.004，筛查结论相同。
5. **换训练内场景和原尺寸 32 张后是否保持** → **待 A3**（跨场景角色上已失效：MAE 劣于零基线）。
6. **是否找到符合预定条件的非零修改** → **没有**：仍为全部拒绝（覆盖 0，safe=true，useful=false）。
7. **限制**：单种子；继承权重已见过这些场景；24 裁剪而非 1140 帧正式覆盖；固定 500 步终点、无收敛证明；
   偏差/门槛只是诊断级小样本校准、不可部署，B 必须在完整原训练内角色上重新校准。

**对下一阶段的建议（不自动启动）**：A2 未出现"可进入 B"的信号——
pure 未优于 mixed，安全角色选择净改善不为正，原尺寸筛查未做。
建议先定位"幅值低估 + 跨场景不迁移"的根因（输入/目标/上下文），再决定是否值得做正式 loss 对照。
